# Compressed-slice contract (shared)

This is the **slug-mode** output contract, shared by the `/wf intake` mode dispatcher (`reference/intake.md`), every intake mode card that attaches a slice, and `/wf probe` (`reference/probe.md`). When a command resolves to **slug-mode** (see the trigger below), its output is rerouted to **one compressed slice** on that workflow instead of a standalone flow. This contract **overrides** any "create a new workflow", "create a branch", "write a top-level `00-index.md`", or "write a standalone `01-<op>.md` / off-pipeline artifact" instruction in the calling reference. The reference's *content discipline* (research, sub-agents, body sections, analysis depth) still applies in full; only the *output destination* and *index bookkeeping* change.

Throughout, `<op>` is the operation that produced the slice: an intake mode (`fix`, `rca`, `investigate`, `discover`, `hotfix`, `refactor`, `update-deps`, `ideate`, `audit`, `brainstorm`, `simplify`, `task`) or `probe`.

## The trigger and the mode cards

- **Trigger.** Slug-mode starts on one test: `node "<skill-dir>/scripts/wf.mjs" record get "<root>" <slug> index` exits 0 for the token before the mode word (branch 1 of `reference/intake.md`; a closed workflow asks first).
- **Own type.** When the `workflow-type` of that workflow is the mode itself (`brainstorm`, `audit`, `task`), the run is a resume of the standalone flow, not slug-mode.
- **`origin`.** An intake mode writes `origin: intake/<op>`. `probe` writes `origin: probe`.
- **Mode cards.** An intake mode card cites this contract in one line and keeps no copy of it. A card with a real exception adds one exception line.

## Inline records — a compressed slice spawns no children

A compressed slice carries its records **inline in the artifact body** and never spawns child artifacts. This contract promises *exactly one artifact*, and every caller relies on that. Two callers this rule binds concretely:
- A slice-mode **task** records its per-AC evidence rows (with `evidence-rung`) in a body table; it writes no `06-verify.md`.
- A slice-mode **audit** records a single findings table in the body and **does not accumulate**: a slice-mode audit is a one-shot audit, and its body states that. The accumulating ledger (`_findings-ledger.md`) applies only to the standalone audit workflow's `07-review*` family.

## Slice-slug derivation

- Form: `<op>-<short-descriptor>` (lowercase kebab-case, ≤5 words).
- Source the descriptor from the command's first descriptive argument when available (for example `/wf intake <slug> rca "payment spike"` → `rca-payment-spike`). If there is no descriptive argument or it is generic, fall back to `<op>-<utc-date>` (for example `ideate-2026-06-18`).
- Collision: if `node "<skill-dir>/scripts/wf.mjs" record list "<root>" <slug>` already names `03-slice-<slice-slug>.md`, append `-2`, `-3`, … until unique.

## Write exactly one artifact

Write the draft `<wf-dir>/.draft/03-slice-<slice-slug>.md` per [_records.md](_records.md), with this frontmatter shape:

```yaml
---
schema: sdlc/v1
type: slice
slug: <slug>
slice-slug: <slice-slug>
slice-type: <op>            # fix | rca | probe | investigate | discover | hotfix | update-deps | refactor | ideate | simplify | audit | task | brainstorm
compressed: true
origin: intake/<op>         # probe writes origin: probe
status: defined
stage-number: 3
created-at: "<real UTC timestamp per _timestamp.md>"
updated-at: "<same>"
complexity: <xs|s|m|l|xl>   # estimate from the op's own analysis; use xs when not applicable (e.g. a pure rca diagnosis)
depends-on: []
tags: []
refs:
  index: 00-index.md
  slice-index: 03-slice.md  # OMIT this key if 03-slice.md does not exist
---
```

**Body shape:** start with a `# Compressed Slice: <op>` heading and a one-line provenance preamble (for example ``Generated by `/wf intake <op>` on <iso-date> against slug `<slug>`.``). Then write the same content sections the standalone reference would have written to its primary artifact (the research findings, plan, diagnosis, recommendations, and so on) under the same section headings. Write no separate standalone artifact. Then run `node "<skill-dir>/scripts/wf.mjs" record put "<root>" <slug>`.

## Index updates (after the put of the slice record)

Run one command. It appends to both lists and moves `updated-at` itself:

```
node "<skill-dir>/scripts/wf.mjs" record set "<root>" <slug> index "workflow-files+=03-slice-<slice-slug>.md" "compressed-slices+={slug: <slice-slug>, slice-type: <op>, created-at: <iso>}"
```

Change no other field of the index: not `current-stage`, `stage-number`, `selected-slice`, `status`, `branch` or `progress`. The compressed slice is additive. It does not advance the main lifecycle.

## Slice-index update (conditional)

When `node "<skill-dir>/scripts/wf.mjs" record get "<root>" <slug> 03-slice.md --fields total-slices` exits 0, it prints `total-slices: <n>`. Run one command:

```
node "<skill-dir>/scripts/wf.mjs" record set "<root>" <slug> 03-slice "slices+={slug: <slice-slug>, status: defined, slice-type: <op>, compressed: true}" total-slices=<n+1>
```

Do not change `best-first-slice`: a compressed slice is not part of the planned order. When `03-slice.md` does not exist (the workflow has not reached slicing yet), skip this step. The entry in `compressed-slices` of the index is then the single source of truth.

## Branch behavior and suppressed companions

Switch no branch and create no branch: this **suppresses** any `git checkout -b` step in the standalone reference (for example `hotfix/<slug>`, `refactor/<slug>`, `fix/<slug>`). If the current git branch differs from the workflow's `branch` field, surface a one-line warning in the chat return but proceed; the artifact lives in the workflow dir, not on a specific branch.

In slug-mode the compressed slice is the **sole output**. Write none of the standalone off-pipeline companion artifacts (`.ai/dep-updates/<run-id>/…`, `.ai/ideation/…`, `.ai/simplify/<run-id>.md`); their substance goes into the compressed slice body instead.

## What standalone instructions may not do in slug-mode

- Create a new directory under `.ai/workflows/`.
- Write a new top-level `00-index.md`.
- Write a standalone `01-<op>.md` / `hf-*` / `rf-*` artifact at the workflow root, or an off-pipeline companion under `.ai/dep-updates/`, `.ai/ideation/`, `.ai/simplify/`.
- Run `git checkout -b` or any branch-creating command.
- Set `current-stage` or `selected-slice` on the existing `00-index.md`.

## Chat return for slug-mode

One line, `<op> → compressed slice <slice-slug> on <slug>`, followed by the downstream recommendation the standalone op would have surfaced (for example rca's "consider `/wf intake refactor` for finding X"). The recommendation applies to the new slice. The router's mandatory Final Summary (narrative-first) still applies.
