# Compressed-slice contract (shared)

This is the **slug-mode** output contract, shared by the `/wf intake` mode dispatcher (`reference/intake.md`), `/wf probe` (`reference/probe.md`), `/wf simplify` (`reference/simplify.md`), and `/wf task` (`reference/task.md`). When a command resolves to **slug-mode** (its first positional token is an existing, non-closed workflow slug, so `.ai/workflows/<slug>/00-index.md` exists), its output is rerouted to **one compressed slice** on that workflow instead of a standalone flow. This contract **overrides** any "create a new workflow", "create a branch", "write a top-level `00-index.md`", or "write a standalone `01-<op>.md` / off-pipeline artifact" instruction in the calling reference. The reference's *content discipline* (research, sub-agents, body sections, analysis depth) still applies in full; only the *output destination* and *index bookkeeping* change.

Throughout, `<op>` is the operation that produced the slice: an intake mode (`fix`, `rca`, `investigate`, `discover`, `hotfix`, `refactor`, `update-deps`, `ideate`, `audit`), `probe`, `simplify`, or `task`.

## Inline records — a compressed slice spawns no children

A compressed slice carries its records **inline in the artifact body** and never spawns child artifacts. This contract promises *exactly one artifact*, and every caller relies on that. Two callers this rule binds concretely:
- A slice-mode **task** records its per-AC evidence rows (with `evidence-rung`) in a body table; it writes no `06-verify.md`.
- A slice-mode **audit** records a single findings table in the body and **does not accumulate**: a slice-mode audit is a one-shot audit, and its body states that. The accumulating ledger (`_findings-ledger.md`) applies only to the standalone audit workflow's `07-review*` family.

## Slice-slug derivation

- Form: `<op>-<short-descriptor>` (lowercase kebab-case, ≤5 words).
- Source the descriptor from the command's first descriptive argument when available (for example `/wf intake <slug> rca "payment spike"` → `rca-payment-spike`). If there is no descriptive argument or it is generic, fall back to `<op>-<utc-date>` (for example `ideate-2026-06-18`).
- Collision: if `.ai/workflows/<slug>/03-slice-<slice-slug>.md` already exists, append `-2`, `-3`, … until unique.

## Write exactly one artifact

Write `.ai/workflows/<slug>/03-slice-<slice-slug>.md` with this frontmatter shape:

```yaml
---
schema: sdlc/v1
type: slice
slug: <slug>
slice-slug: <slice-slug>
slice-type: <op>            # fix | rca | probe | investigate | discover | hotfix | update-deps | refactor | ideate | simplify | audit | task
compressed: true
origin: wf/<op>             # e.g. intake/rca, probe, simplify
status: defined
stage-number: 3
created-at: "<real UTC timestamp per _timestamp.md>"
updated-at: "<same>"
complexity: <xs|s|m|l|xl>   # estimate from the op's own analysis; use xs when not applicable (e.g. a pure rca diagnosis)
depends-on: []
tags: []
refs:
  index: 00-index.md
  slice-index: 03-slice.md  # OMIT this key if 03-slice.md does not exist
---
```

**Body shape:** start with a `# Compressed Slice: <op>` heading and a one-line provenance preamble (for example ``Generated by `/wf intake <op>` on <iso-date> against slug `<slug>`.``). Then write the same content sections the standalone reference would have written to its primary artifact (the research findings, plan, diagnosis, recommendations, and so on) under the same section headings. Write no separate standalone artifact.

## Index updates (after writing the slice file)

1. Read `.ai/workflows/<slug>/00-index.md`.
2. Append `03-slice-<slice-slug>.md` to `workflow-files`.
3. Append `{slug: <slice-slug>, slice-type: <op>, created-at: "<iso>"}` to a top-level `compressed-slices:` array. Create the array if it does not exist on the index yet.
4. Update `updated-at` to the current ISO timestamp.
5. Leave `current-stage`, `stage-number`, `selected-slice`, `status`, `branch`, and `progress` unchanged. The compressed slice is additive; it does not advance the main lifecycle.
6. **Global registry.** Open `.ai/workflows/INDEX.md`. Locate the row whose first tab-separated column equals `<slug>`. Rewrite **only** the `updated-at` column (last column) to the same ISO timestamp used in step 4; leave `status`, `workflow-type`, and `branch` unchanged, because the parent workflow's lifecycle position is unchanged. If the row is missing (registry drift), append a new row using the values just read from `00-index.md` (`<slug>\t<status>\t<workflow-type>\t<branch>\t<updated-at>`); the next `/wf status` reconciles sort order.

## Slice-index update (conditional)

If `.ai/workflows/<slug>/03-slice.md` exists: read it; append `{slug: <slice-slug>, status: defined, slice-type: <op>, compressed: true}` to `slices`; bump `total-slices` by 1; update `updated-at`; leave `best-first-slice` unchanged, because compressed slices are additive, not part of the planned implementation order. If `03-slice.md` does not exist (the workflow has not reached slicing yet), skip this step entirely; the entry in `00-index.md.compressed-slices` is the single source of truth.

## Branch behavior and suppressed companions

Switch no branch and create no branch: this **suppresses** any `git checkout -b` step in the standalone reference (for example `hotfix/<slug>`, `refactor/<slug>`, `fix/<slug>`). If the current git branch differs from the workflow's `branch` field, surface a one-line warning in the chat return but proceed; the artifact lives in the workflow dir, not on a specific branch.

In slug-mode the compressed slice is the **sole output**. Write none of the standalone off-pipeline companion artifacts (`.ai/dep-updates/<run-id>/…`, `.ai/ideation/…`, `.ai/simplify/<run-id>.md`); their substance goes into the compressed slice body instead.

## What standalone instructions may not do in slug-mode

- Create a new directory under `.ai/workflows/`.
- Write a new top-level `00-index.md`.
- Write a standalone `01-<op>.md` / `hf-*` / `rf-*` artifact at the workflow root, or an off-pipeline companion under `.ai/dep-updates/`, `.ai/ideation/`, `.ai/simplify/`.
- Run `git checkout -b` or any branch-creating command.
- Set `current-stage` or `selected-slice` on the existing `00-index.md`.

## Chat return for slug-mode

One line, `<op> → compressed slice <slice-slug> on <slug>`, followed by the downstream recommendation the standalone op would have surfaced (for example rca's "consider `/wf intake refactor` for finding X"). The downstream recommendation is still valid; it is now scoped to the new slice rather than a fresh workflow. The router's mandatory Final Summary (narrative-first) still applies.
