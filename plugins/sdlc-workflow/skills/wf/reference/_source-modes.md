# Source modes (single source)

The `workflow-type` of `00-index.md` sets the source mode of a workflow: which record leads, where the acceptance criteria are, which names the records have, and what implement, verify and review do. This table owns the source modes. `implement.md`, `verify.md`, `review/_stage.md`, `probe.md` and `yolo.md` cite it.

Read each record with `wf.mjs record get`. A stage whose action is STOP writes no artifact: it gives the route and stops.

| `workflow-type` | Lead record | Acceptance source | Record names | implement | verify | review |
|---|---|---|---|---|---|---|
| `feature`, or unset (standard) | `01-intake.md` | `03-slice-<slice>.md` and `02-shape.md` | Suffixed with the slice: `03-slice-<slice>.md`, `04-plan-<slice>.md`, `05-implement-<slice>.md`, `06-verify-<slice>.md`. | Build the slice. | Check the slice. | Review. |
| `fix`, `hotfix`, `refactor` (legacy `rf`): change mode | `01-<mode>.md` (`type: intake`) | `01-<mode>.md`, not `03-slice.md` | Not suffixed, one slice: `02-shape.md`, `03-slice.md`, `04-plan.md`, `05-implement.md`, `06-verify.md`. `selected-slice` names the slice. hotfix: `02-shape.md` holds `## Root Cause`. refactor: `02-shape.md` holds the API-surface baseline. | Build as standard. refactor: one green step and one commit for each plan step, never combined; when verify fails, fix the refactor, not the test. | Check as standard. hotfix: reproduce the incident symptom and run the regression suite. refactor: run the `## Baseline Command` of `02-shape.md` again, compare its pass, fail and skip counts with `## Baseline Test Result`, and check that each `## Public API Surface` name keeps its signature and that its callers work. An unplanned deviation is a FAIL. | Review as standard, slug-wide. The default rubric of hotfix is `security`, and of refactor `refactor-safety`. |
| `rca`: forwarded mode | `01-rca.md` | `01-rca.md` and the synthesized `02-shape.md` | Not suffixed. `04-plan.md` exists only when `/wf plan` ran after the forward. | Build from `01-rca.md` and the plan. | Check. | Review. |
| `quick` (legacy): compressed mode | `01-quick.md` | `01-quick.md` | `05-implement.md`, `06-verify.md`. No shape, slice or plan record. | Build from `01-quick.md`, which holds the plan. | Check. | Review. |
| `update-deps`: self-managed | `01-update-deps.md` | `01-update-deps.md` and the P0, P1 and P2 tiers of `03-slice.md` | Not suffixed: `04-plan.md`; the flow writes its own `05-implement.md` and `06-verify.md`. | STOP. Route: `/wf intake update-deps <slug>`. | STOP. Route: `/wf intake update-deps <slug>`. | Review slug-wide against `01-update-deps.md` and `03-slice.md`. |
| `optimize` | `01-optimize.md`; the confirmed `02-optimize-spec.md` replaces shape and plan | `03-slice-optimize.md` | One slice, `optimize`: `03-slice-optimize.md`, `05-implement-optimize.md`, `06-verify-optimize.md`. No plan record. | STOP: the loop is the implement stage. Route: `/wf loop optimize <slug>`. | Check the slice `optimize`. | Review against `02-optimize-spec.md`. Always add `correctness` with `focus: metric-gaming`. |
| `small` | `01-small.md` | `## Acceptance Checks` of `01-small.md` | `01-small.md` is the plan, implement and verify record. The changed code is the commits in its `commit-sha`. | STOP: the small path built it. Route: the `next-invocation` of the index. | STOP: the small path checked it. Route: the `next-invocation` of the index. | Review slug-wide, only when `progress.review` is `not-started` or later. When it is `skipped`, STOP: "This small-path workflow has no PR. Run `/wf review <dimension>` for an ad-hoc review of the commit." |
| `task` | `01-task.md` | `01-task.md` | The flow writes its own `05-implement.md` and `06-verify.md`. No slice or plan record. | STOP. Route: `/wf intake task <slug>`. | STOP. Route: `/wf intake task <slug>`. | STOP: "This is a task workflow. Resume it with `/wf intake task <slug>`. When the task left a diff to review, run `/wf review <dimension>` on it." |
| `audit` | `01-audit.md` | none: the ledger holds the findings of the audit (`--source audit`) | `findings.yaml` and `07-review.md`. No implement record. | STOP. Route: `/wf intake audit <slug>`. | STOP. Route: `/wf intake audit <slug>`. | STOP: "This is an audit workflow. Its ledger belongs to `/wf intake audit <slug>`; run that again to merge new findings." |
| `investigate`, `discover`, `ideate`, `brainstorm`: terminal analysis | `01-<mode>.md` | none: no `02-shape.md` | No slice, plan or implement record. | STOP. Route: the next step that the lead records, for example `/wf intake <option>` for a chosen option, as a new workflow. | STOP, with the same route. | STOP, with the same route. |

Never fall through to the standard mode for a `workflow-type` that this table names with STOP.
