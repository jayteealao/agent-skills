sdlc-workflow

A Claude Code plugin that runs software work as a disciplined lifecycle. Each stage asks the right questions, writes its decisions to durable artifacts in your repo, and gates progress on evidence instead of optimism.

You drive everything through one command, /wf. A feature moves through ten stages. Each stage writes a numbered artifact under .ai/workflows/<slug>/. The next stage, a colleague, or a future session can continue from that artifact alone:

  • intake
  • shape
  • slice
  • plan
  • implement
  • verify
  • review
  • handoff
  • ship
  • retro

Small work takes a shortcut. /wf intake fix compresses the early stages into one run and starts you at implementation. Investigation modes answer questions without building anything. Two drivers, auto and yolo, sequence the stages for you. Everything you produce renders into a live dashboard served on your machine.
